# SaaSForge

A modern, scalable, B2B multi-tenant SaaS starter kit.

## Features
- **Frontend**: Next.js 15, Tailwind v4, Base UI
- **Backend**: FastAPI, SQLAlchemy (async), PostgreSQL, Redis
- **Auth**: JWT, API Keys, RBAC
- **Multi-Tenancy**: Organization-based row-level isolation
- **DevOps**: Docker, GitHub Actions CI/CD
